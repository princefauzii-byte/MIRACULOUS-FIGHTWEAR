# MIRACULOUS Fightwear

Website e-commerce fightwear yang dibuat untuk tugas Slicing Website menggunakan HTML, CSS, dan JavaScript.

## Deskripsi

MIRACULOUS Fightwear merupakan website e-commerce yang menyediakan berbagai perlengkapan olahraga bela diri seperti Boxing, Muay Thai, MMA, dan Apparel.

Website ini memiliki beberapa fitur seperti halaman Home, katalog produk, kategori produk, About, serta Shopping Cart.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
