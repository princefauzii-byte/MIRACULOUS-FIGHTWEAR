# MIRACULOUS Fightwear

Website e-commerce fightwear untuk tugas **Slicing Website HTML/CSS/JS**.

## Ketentuan yang diterapkan
- HTML5
- Plain CSS (tanpa Tailwind CSS / Bootstrap)
- JavaScript DOM
- Responsive: desktop, tablet, mobile
- Search produk
- Filter kategori
- Sorting harga
- Product detail modal
- Shopping cart
- Quantity control
- Wishlist interaction
- Newsletter form validation
- Mobile navigation
- LocalStorage untuk menyimpan cart

## Struktur
```text
MIRACULOUS-FIGHTWEAR/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── logo/
    │   └── miraculous-logo.png
    ├── products/
    └── hero/
```

## Cara menjalankan
Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.

## Catatan
Foto produk belum digunakan karena aset produk belum tersedia. Product visual sementara dibuat dengan CSS sehingga website tetap bisa didemokan. Aset produk dapat dimasukkan kemudian ke folder `images/products/`.

## Deployment
Project ini siap di-deploy ke GitHub Pages, Netlify, atau Vercel.
